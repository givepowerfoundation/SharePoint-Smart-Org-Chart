## How to capture

1. Open the web part in SharePoint (production or the SharePoint workbench with demo data enabled).
2. Use the Windows Snipping Tool (`Win + Shift + S`), browser DevTools device emulation, or any screenshot utility.
3. Recommended width: **1280 px** for full-width shots, **640 px** for panel/card close-ups.
4. Save files as PNG with the exact filenames listed above.
